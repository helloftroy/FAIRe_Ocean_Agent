# INSDC /geo_loc_name vocabulary used for the strict-FAIRe correction

Retrieved 2026-11-10. Used by scripts/faire_strict/geo.py (rule R21 in
correct_to_faire.md). Checksums are in SHA256SUMS.txt.

- Page: https://www.insdc.org/submitting-standards/geo_loc_name-qualifier-vocabulary/
  (the FAIRe checklist links http://insdc.org/country.html, which now returns
  404; INSDC renamed the /country qualifier to /geo_loc_name in 2024).
- Page states: "Revised July 08, 2024".
- geo_loc_name_qualifier_vocabulary_2024-07-08.html: the page as downloaded.
- geo_loc_name_current.txt: the 280 current names, extracted from the page.
- geo_loc_name_historical.txt: the 17 "Historical geo_loc_names".
- Value format (INSDC): "<geo_loc_name>[:<region>][, <locality>]".
